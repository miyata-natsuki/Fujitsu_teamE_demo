# mogu プレゼン トークスクリプト(約7分)

※話す速さは1分あたり約300字を想定。全体で約1,750字(約6分)に、画面操作や間の時間を加えて7分程度です。

## 1. 「いただきます」を、全員で。(約30秒)

みなさん、食事で一番うれしい瞬間はいつですか。私は、テーブルを囲んで、みんなで「いただきます」と声をそろえる瞬間だと思います。食事は、おなかを満たすだけの時間ではありません。会話が生まれ、距離が縮まり、思い出が残る、人と人をつなぐ大切な時間です。私たちは、その時間を「誰も取り残さず、美味しく共有すること」を実現したいと考えています。そのために作ったのが、食べられない食材から選ぶお店探しアプリ、moguです。本日は七分間で、その仕組みと可能性をお伝えします。

## 2. 「何でもいいよ」が、いちばん困る(約1分)

まず、幹事の立場を想像してください。友人との食事会、家族の記念日、職場の歓送迎会。お店を決める場面で「何でもいいよ」と言われるのが、実は一番困ります。参加者の中には、アレルギーがある人、苦手な食材がある人、宗教や文化の理由で食べられないものがある人がいます。本人は「自分のせいで迷惑をかけたくない」と遠慮して言い出せず、幹事は「誰かが食べられなかったらどうしよう」と不安になります。楽しいはずの食事が、気づけばストレスの時間に変わってしまう。これは、特別な人の話ではなく、誰にでも起こりうる身近な悩みです。

## 3. 探しても、安心できるお店が見つからない(約1分)

では、今はどうやってお店を探しているでしょうか。検索サイトで候補を出し、口コミを読み、それでも分からなければ、お店に電話で一軒ずつ確認します。手間がかかるうえに、お店の忙しい時間帯には聞きづらく、情報が足りないまま不安は消えません。そして最終的に、全員が確実に食べられるお店ではなく、「無難なお店」を選ぶことになります。原因は、既存の飲食店検索・予約サービスが、料理のジャンルや価格、評価で探す仕組みになっていて、食べられない食材では絞り込めないことにあります。探す基準そのものが、この課題に合っていないのです。

## 4. 食べられない食材から選ぶ「mogu」(約1.5分)

そこで私たちが提案するのが、moguです。使い方は三つのステップです。まず、自分の食べられない食材と、苦手な食材、好きな食材を登録します。名前の読み方や別名でも探せるので、入力に迷いません。次に、招待リンクを送るだけで、友人や家族をグループに追加できます。すると、全員が食べられるお店だけが、除外されたお店の理由とともに表示されます。さらに、参加者ごとにおすすめのメニューも提案するので、「自分は何を頼めばいいか」まで迷いません。この流れは、すでに動くプロトタイプとして実装しています。ぜひ、実際に動かしてご覧ください。

## 5. 「行きたい店」から「みんなが行ける店」へ(約1.5分)

moguの独自性は、探す基準を変えたことです。従来は「行きたいお店を探す」サービスでしたが、moguは「みんなが安心して行けるお店を探す」サービスです。特に大切にしているのが、安全側の判断です。アレルゲンが未確認のお店やメニューは、おすすめ度が高くても、候補から外します。好みの点数で、安全性を緩めることはありません。お店側の負担も小さくしました。メニュー表やレシートの写真を撮るだけで、文字を読み取って登録できます。さらに、日本語、英語、中国語、韓国語の四言語に対応し、多様な背景の方が同じ画面で使えます。単なる検索アプリではなく、食体験を支える仕組みです。

## 6. 利用者・お店・社会、三方よし(約1分)

moguがもたらす価値は、三方よしです。まず利用者には、安心して選べる体験があります。幹事は、一軒ずつ確認する手間から解放されます。次に飲食店には、新しい集客の機会があります。これまで来店をためらっていた、食に制約のあるお客様と、そのグループ全体が来てくれるようになります。特に、一人ひとりに丁寧に対応できる個人店の魅力を、正しく届けることができます。そして社会にとっては、食の多様性への配慮が当たり前になる一歩です。誰かが我慢するのではなく、みんなで選べる。それが当たり前になれば、外食はもっと自由で、もっと楽しい時間になります。

## 7. 食の制約が、壁にならない未来へ(約30秒)

最後に、今後の展望です。まず対象の店舗とエリアを広げ、お店自身が確認した情報を登録する仕組みを整えます。実際の運用では、アレルギー情報の正確性が何より大切ですので、お店への確認を前提とした設計を進めます。将来は、旅行やインバウンド、学校給食や企業の会食など、あらゆる食の場面に広げていきます。食の制約が、人と人を隔てる壁にならない未来へ。次の食事は、全員で「いただきます」を。ご清聴ありがとうございました。
